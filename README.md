# 同じ廊下 – 第1段階 3D基礎プロトタイプ

一人称視点の3D心理ホラー『同じ廊下』の基礎プロトタイプです。  
Three.js + 静的ファイル構成で、iPhone Safari から直接遊べます。

## ファイル構成（GitHub Pages用）

```
├── index.html   … エントリーポイント
├── style.css    … タッチUI・レイアウト
├── game.js      … ゲームロジック一式
└── README.md
```

Three.js は CDN から読み込みます（`three.min.js` は不要）。

## 操作方法

### スマートフォン（推奨）
- **左下の仮想ジョイスティック** … 移動（前後左右）
- **画面右側をドラッグ** … 視点操作（上下左右）
- 両手同時操作可能

### PC（補助）
- WASD / 矢印キー … 移動
- マウスドラッグ … 視点

## GitHub Pages への配置方法

1. GitHub で新しいリポジトリを作成（例: `same-corridor`）
2. この3ファイル（`index.html` / `style.css` / `game.js`）をリポジトリの**ルート**にアップロード  
   （または `docs` フォルダに入れて Settings で `/docs` を指定）
3. リポジトリの **Settings → Pages**  
   - Source: `Deploy from a branch`  
   - Branch: `main`（または `master`） / `/ (root)` を選択して Save
4. 1〜2分待つと `https://<あなたのユーザー名>.github.io/same-corridor/` で公開されます

iPhone の Safari でその URL を開けばすぐ遊べます。

## ローカルで確認する場合

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。  
`file://` で直接開くと動作しないことがあるので、必ず HTTP サーバー経由で確認してください。

## 第1段階で実装した機能

- Three.js によるリアルタイム3D空間
- 一人称カメラ（目線高さ・ピッチ制限）
- 仮想ジョイスティック + タッチ視点操作（同時操作対応）
- 壁・家具・ドアとの衝突判定
- カメラ追従の懐中電灯
- 薄暗い環境光
- 細長い直線廊下（約42m）
- 立体的な家具3点（棚+花瓶 / テーブル / 額縁付き風景画）
- 奥の閉じたドア
- 画面リサイズ対応・エラー表示

- 敵・追跡・エンディング
